# Версия для GitHub

Репозиторий: https://github.com/Isa-88/Export-AA

## Запуск после скачивания

```sh
git clone https://github.com/Isa-88/Export-AA.git
cd Export-AA
python -m app.server
```

Python 3.11 или новее, без внешних пакетов для запуска. Откройте http://127.0.0.1:8080. Панель: /admin, случайный пароль печатается при запуске. Не публикуйте пароль в Issues или коммитах. Для постоянного пароля используйте локальную .env по примеру .env.example.

Включены код, тесты, подготовленные бизнес-данные FAQ/каталога, отчёты и метаданные источников. Исходные PDF, фотографии, медиа и RAR не включены. Ссылки на их страницы служат происхождением записи; полный оригинал не будет доступен из этой поставки.

Не включены рабочая SQLite-база, переписки тестового сервера, .env, пароли, резервные копии и временные файлы. На первом запуске создаётся чистая база. Телефоны и адреса электронной почты в публикуемой копии обезличены; это не влияет на сохранённый локальный оригинал. Контакты нужно отдельно согласовать и настроить через защищённую панель.

В RELEASE_MANIFEST.json указаны SHA-256 файлов опубликованной копии. SHA исходных документов в source-метаданных относятся к оригиналам, а не к обезличенному тексту. RELEASE_CHECKS.txt содержит результат проверки этой поставки. Общедоступная лицензия на сторонние каталоги и документы этой поставкой не предоставляется.

## Проверки

```sh
python -m unittest discover -s tests -v
```

GitHub Actions настроен на Python 3.11 и 3.14. Его облачный результат проверяется отдельно от локального прогона; наличие workflow не означает, что он уже прошёл на GitHub.

## Повторная сборка

Из полной рабочей копии: `python -m scripts.package_release`. Создаётся новая папка и ZIP в dist без изменения предыдущих архивов. Для повторной сборки после правок нужен новый запуск. Скрипт использует список разрешённых папок и файлов; секреты и базы данных не копируются. Перед публикацией проверяйте новые данные на персональные сведения.

Это серверный Python-проект: GitHub Pages не запускает его. Публикация исходников не включает реальные каналы. Инструкции внешнего подключения находятся в integrations.md.
