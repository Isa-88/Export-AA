# Помощник Арслана-Али — локальный прототип v3

Единая база знаний, русско-английский чат, каталог, заявки и защищённая панель команды. **Демонстрационный режим: реальные сообщения, уведомления и бронирования не отправляются.**

## Запуск

Для скачанной версии из репозитория начните с [инструкции GitHub](docs/github.md).

Python 3.11+ с SQLite; проверено на Windows / Python 3.14.3. Для запуска подготовленного проекта сторонние библиотеки и npm не нужны.

```powershell
cd "C:\Users\user\Documents\ChatGPT\для Экспортёров"
python -X utf8 -m app.server
```

Чат: http://127.0.0.1:8080 — панель: http://127.0.0.1:8080/admin.
Пароль владельца выводится в терминал при запуске. Остановка: Ctrl+C.

Для постоянных настроек скопируйте `.env.example` в `.env`, только если своей `.env` ещё нет. Укажите `ADMIN_PASSWORD` от 16 символов. Необязательные `MANAGER_PASSWORD` и `REVIEWER_PASSWORD` должны отличаться от остальных паролей. Менеджер работает с диалогами и заявками; редактор проверяет знания без доступа к клиентским данным; владелец утверждает актуальные предложения и выполняет удаление. Секреты остаются на сервере. После перезапуска требуется новый вход, история в SQLite сохраняется; веб-сессия клиента временная.

## Что реализовано

- 140 общих записей FAQ, каждая с RU/EN версиями и ссылками на источники. Поиск по смысловым словарям, словам и опечаткам; единый сценарный движок на двух языках.
- Автоматический выбор RU/EN по содержательному сообщению, ручные Auto/RU/EN и команды `/auto`, `/ru`, `/en`. Смена языка сохраняет заявку, количество, единицы и паузу человека. Разовый перевод предыдущего парного ответа не меняет выбранный язык.
- 308 записей каталога из доступного текста: коллекция, полный SKU, вариант, версия документа и страница. Неизвестные цены и наличие остаются неизвестными. Подборка содержит несколько товарных строк; изменение количества обновляет строку.
- Постепенный сбор заявки, RU/EN резюме, `/summary`, новый независимый проект через `/new`, статусы и ответственный. Исходный канал пригоден для ответа — телефон не обязателен.
- Передача человеку сохраняет заявку и останавливает автоматические деловые ответы. Менеджер может ответить в локальном чате и явно возобновить бота.
- Панель: диалоги, заявки, FAQ, товары, услуги, миссии, кейсы, источники, конфликты, пробелы медиа, версии и откат. Изменения без редактирования кода.
- Повторные события не создают дубли, включая конкурентную обработку. Ошибки демонстрационной доставки учитываются; после трёх неудач запись требует ручного разбора.
- Запросы отписки и удаления. Удаление владельцем ограничено указанным диалогом; анонимный аудит и технические отметки повторных событий сохраняются. Резервные копии требуют отдельной политики удаления.

## Архитектура

```text
Web / Telegram / Instagram → dialogue.Engine → поиск FAQ и товаров
                                  │                  │
                             SQLite / действия ← единые записи RU/EN
                                  │
                            панель команды / аудит
```

- `app/dialogue.py`, `language.py`: контекст, языки, сценарии и серверные действия.
- `app/models.py`, `storage.py`: сущности, миграция v3, версии, одобрения, SQLite.
- `app/search.py`: общий двуязычный поиск и проверка актуальности источников.
- `app/prepare_sources.py`, `import_data.py`: подготовка архива и повторяемый импорт.
- `app/server.py`, `adapters.py`: HTTP, сессии, роли, CSRF, лимиты и входящие адаптеры.
- `static/`: интерфейсы без CDN. `app/core.py` — сохранённое старое ядро только для регрессионных тестов, сервер использует v3.

Клиентские сообщения отделены от знаний. Идентичности разных каналов не объединяются по имени. Инструкции в сообщениях и источниках не выполняются. Сервер доступен только на localhost, проверяет Host/Origin, авторизацию и CSRF. База на диске не зашифрована.

## Источники и утверждение

Приложение было одним составным Markdown. Из него восстановлены `package/MASTER_PROMPT.md`, `SOURCE_REVIEW.md`, `FAQ_RU_EN.md` и `faq_ru_en.json`; происхождение и SHA записаны в `package_manifest.json`. Это восстановленные разделы, а не отдельно предоставленные файлы. RAR безопасно распакован в `sources/archive/ChatExport_2026-09-16`.

FAQ импортированы как **draft**. Локальный чат показывает такие ответы с отметкой проекта; это не коммерческое согласование. Архивные наблюдения о ценах отделены от текущих предложений. Консультация 10 000 ₽/час — единственный стартовый текущий ценовой факт из прямого задания владельца через заказчика. Бесплатный приём описания не называется бесплатной экспертной консультацией.

В панели откройте запись, проверьте обе языковые версии, источник и срок действия. Для `approved_current` требуется роль владельца, основание и срок актуальности. Изменение цены услуги переводит её в черновик и снимает актуальность зависимых пар FAQ; требуется новое согласование. Откат создаёт черновик. Отзыв источника блокирует связанные ответы и товары, включая сохранённый парный ответ. Утверждение всего архива одной отметкой не предусмотрено.

`source_observed` означает наблюдение в источнике, а не независимую проверку. `historical` — прошлое событие. Импорт повторяем: существующие редакции и согласования не перезаписываются. Основная рабочая база — `data/assistant.sqlite3`, JSON служат исходными данными.

## Проверки и обслуживание

```powershell
python -X utf8 -m unittest discover -s tests -v
python -X utf8 -m tests.transcripts
python -X utf8 -m app.maintenance backup
python -X utf8 -m app.maintenance prune
```

`prune` по умолчанию только показывает число диалогов старше `RETENTION_DAYS` (180). Удаление выполняется лишь с `--apply`; срок можно задать `--days`. Копии создаются SQLite Backup API в `backups/`. Перед восстановлением остановите сервер и сохраните текущую БД. Миграция выполняется при запуске, перед обновлениями делайте копию.

Для повторной подготовки оригинальных источников нужен `pdfplumber` и системный `tar` с поддержкой RAR (в этой среде доступны):

```powershell
python -X utf8 -m app.prepare_sources --markdown "C:\Users\user\Downloads\Arslan_Ali_Codex_Prompt_RU_EN_v3.md" --archive "C:\Users\user\Downloads\Telegram Desktop\ChatExport_2026-09-16.rar"
python -X utf8 -m app.import_data
```

Новый архив иной версии требует отдельной подготовки и проверки; не заменяйте исходники поверх старой версии вручную.

## Границы прототипа

Это локальный детерминированный движок с двуязычным поиском, а не подключённая языковая модель. Он понимает реализованные RU/EN сценарии, но не гарантирует понимание произвольной формулировки. Произвольный свободный текст клиента не переводится автоматически: команда получает оригинал, структурированное двуязычное резюме и отдельно помеченное совпадение с вопросом FAQ. Арабский не является полноценным сценарием этого этапа.

Фото-поиск, полное OCR, транскрибация аудио/видео, календарь, внешний переводчик/LLM, уведомления и реальная доставка не подключены. Относительные даты локального чата считаются от времени обработки; адаптеры ещё не передают исходную временную метку провайдера. Не использовать это для автоматического подтверждения записи.

Перед внешним запуском нужны проверка официальных контрактов каналов, OAuth/токены, отправитель, HTTPS и сервер для эксплуатации, контакты ответственных, политика данных и приёмка владельцем. `APP_MODE` принимает только `demo`; заполнение ключей не включает реальные отправки.
